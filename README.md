# Java Practice

A Core Java practice repository covering object-oriented programming, exception handling, and Java 8 concepts.

## Overview

This repository contains hands-on Java exercises used to strengthen language fundamentals and move from syntax-level practice toward practical object-oriented programming.

## Focus Areas

- Java fundamentals
- Classes and objects
- Object-oriented programming
- Collections and common data structures
- Exception handling
- Java 8 language features
- Small practice programs

## Getting Started

```bash
git clone https://github.com/majordevbhargav/Java.git
cd Java
```

Compile and run the individual Java programs with a JDK appropriate to the source code.

```bash
javac Program.java
java Program
```

## Learning Direction

The repository is a stepping stone toward a broader Java path:

**Core Java → OOP → Collections → DSA → Concurrency → JVM Internals → JDBC → Spring Boot → Backend Engineering**
